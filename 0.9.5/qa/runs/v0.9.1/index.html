    Scoping audit — why not Full Regression¶

    Per docs/qa/runs/README.md §"Scoped gating".

    1. Enumerate. git log v0.9.0..690990a: 2 commits, no merges. git diff --stat v0.9.0 690990a: src/mcp_gee_sweet/tools/drive/transfer.py (+200/−11), tests/drive/test_transfer.py, docs/qa/tests/drive_transfer.md, docs/known-limitations.md.
    2. Classify. Behavior change in one module: how download/sync destination paths are built from Drive names.
    3. Map to domains. Only drive_transfer, and within it only the three tools that write to local_path. Upload, export, and revision tools share the module but not the changed code paths.
    4. Structural? No. There's no shared-helper change outside the destination-path logic, and no server, auth, or cache changes.

    Conclusion: TC-D278 (the fix) plus every v0.9.0 download_file / download_folder / sync_folder case. Unit tests (TC-D249–251 and the new test_transfer cases) are covered by CI on the hotfix branch.
