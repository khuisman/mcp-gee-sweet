## Observations

**link_url auto-underline (TC-D181):** Google Docs automatically sets `underline: true` on runs with a `link_url`. This is API behaviour, not a tool bug. Test case notes this.

**precedingParagraphIndex (TC-D167):** The Docs API requires an empty paragraph before every table and will not allow deleting it while the table exists. `insert_doc_table` now returns `precedingParagraphIndex` (= tableStartIndex − 1) so callers can delete `[precedingParagraphIndex, tableEndIndex]` in one range for a clean full-table removal.

**Cleanup pattern confirmed:** `delete_doc_range({start: precedingParagraphIndex, end: tableEndIndex})` removes both the preceding paragraph and the table body in one call, leaving no leftover paragraphs.
