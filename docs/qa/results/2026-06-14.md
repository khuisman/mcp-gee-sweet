## Failures

**TC-R12 — Multiple valid queries**  
Expected: two sheet results with data, no `error` field.  
Observed: both queries return `{"error": "Missing required keys (spreadsheet_id, sheet, range)"}`. `range` is enforced as required by the implementation even though `get_sheet_data` accepts no range. The test cases (and tool intent) assume `range` is optional.

**TC-R13 — One query with missing required keys**  
Expected: Sales sheet succeeds; second (invalid) query returns error.  
Observed: both queries fail with "Missing required keys" — the valid Sales query also fails because `range` is absent.

**TC-R14 — All queries fail**  
Expected: both results have `error` fields referencing sheet-not-found.  
Observed: both results fail with "Missing required keys" instead — the sheet-not-found path is never reached.

**Root cause (R12–R14):** `get_multiple_sheet_data` validates that each query dict contains `spreadsheet_id`, `sheet`, **and** `range`. `range` should be optional (defaulting to full sheet, like `get_sheet_data` does).
