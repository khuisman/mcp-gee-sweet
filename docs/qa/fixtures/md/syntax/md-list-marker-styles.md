# List marker styles

Every marker below is plain, whatever its item's text looks like.

## One list, every shape

1. **whole item bold**
2. **bold lead-in** then plain
3. plain then **bold ending**
4. plain
5. *whole item italic*
6. `whole item code`
7. [whole item link](https://example.com)
8. ~~whole item strikethrough~~
9. **a**
10. **😀**
11. **two** ***adjacent runs***

## Nested

- **bold top**
  - **bold child**
    1. **bold grandchild**
    2. plain grandchild
  - plain child
- plain top

## Tasks

- [x] **checked bold**
- [ ] plain box

## Quoted

> 1. **quoted bold**
> 2. quoted plain

## Blocks inside an item

1. **item with a paragraph**

   paragraph in the item

2. **item after the paragraph**
