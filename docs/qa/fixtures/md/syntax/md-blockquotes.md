### BQ-01 — single-paragraph quote

> A single quoted paragraph.

### BQ-02 — multi-paragraph quote

> First quoted paragraph.
>
> Second quoted paragraph.

### BQ-03 — nested quote

> Outer level.
>
> > Inner level.
> >
> > > Third level.

### BQ-04 — quote containing a list

> Shopping:
>
> - Eggs
> - Milk
>
> 1. Numbered in quote
> 2. Second

### BQ-05 — quote containing a code block

> Run this:
>
> ```
> make deploy
> ```

### BQ-06 — quote containing a heading

> ## Heading in a quote
>
> Text under it.

### BQ-07 — lazy continuation

> This line starts the quote
and this line continues it lazily.

### BQ-08 — quote with inline formatting and a link

> **Bold**, *italic*, `code`, and a [link](https://example.com/q).

### BQ-09 — two quotes separated by a blank line

> First quote.

> Second quote.
