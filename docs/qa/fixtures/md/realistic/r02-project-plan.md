# Project Plan: Customer Portal Redesign

## Overview

This plan covers the redesign of the customer portal, from discovery through launch.
The goal is to cut support tickets about billing by **30%** and raise the portal's
satisfaction score above 4.2.

## Goals

1. **Reduce support load**
   - Self-serve invoice downloads
   - Clear payment-failure messages
2. **Improve navigation**
   - Fewer than three clicks to any account setting
   - A search bar on every page
3. **Meet accessibility standards**
   - WCAG 2.2 AA across all pages

## Timeline

| Phase | Dates | Deliverable |
|-------|-------|-------------|
| Discovery | Oct 1 – Oct 21 | Research summary |
| Design | Oct 22 – Nov 18 | Clickable prototype |
| Build | Nov 19 – Jan 20 | Beta release |
| Launch | Jan 27 | General availability |

## Phases

### Phase 1: Discovery

1. Interview 12 customers across three plan tiers
2. Audit the top 50 support tickets from Q3
3. Map the current navigation
   1. List every page
   2. Record the click depth for each setting
   3. Flag dead ends
4. Write the research summary

### Phase 2: Design

- Wireframes for the five core flows
- Usability tests with 6 participants
  - Two rounds, one week apart
  - Fix critical issues between rounds
- Final visual design

### Phase 3: Build

The build phase runs in two-week sprints. Each sprint ends with a demo.

## Risks

- **Scope creep** from stakeholder requests mid-design
- **Dependency** on the billing API v3, which is still in beta
- Holiday freeze from Dec 20 to Jan 3

## Success metrics

- Billing-related tickets down 30% within 60 days of launch
- Portal CSAT ≥ 4.2
- Zero critical accessibility issues in the external audit
